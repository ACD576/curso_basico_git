# 02 · Brazo robótico de 2 articulaciones

Cinemática directa de varias posturas, espacio de trabajo y cinemática inversa hacia un objetivo.

Para ejecutarlo, abre `brazo.py` en VS Code y pulsa ▶ *Run Python File*.
La imagen aparece en la carpeta `output/`.

**Qué tocar:** `L1`, `L2`, `LIMITES_Q1`, `LIMITES_Q2`, `POSTURAS`, `OBJETIVO`.

**Reto:** encuentra unas longitudes con las que el objetivo `(1.5, 1.5)` sea alcanzable.

**Práctica de Git asociada:** issues (`Fixes #N`), `git revert` de un cambio que rompe el brazo.
